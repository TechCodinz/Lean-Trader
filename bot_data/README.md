# Bot Data Directory

This directory stores learned knowledge and trading history.

## Files:
- strategies.json - Evolved trading strategies
- performance.json - Historical performance metrics
- trades.jsonl - Trade history (line-delimited JSON)
- market_knowledge.json - Learned market patterns
- meta_learning.json - Meta-learning data
- quantum_data.json - Quantum entanglement data

## Backup:
Data is automatically saved here and should be backed up regularly.
Large files (trades.jsonl) are not committed to git.
