🆘 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Bot not starting:
  - Check logs: docker-compose logs trading-bot
  - Verify .env file has API keys
  - Check permissions: chmod +x *.sh

No trades executing:
  - Check balance in .env GATEIO_API_KEY
  - Verify ENABLE_LIVE=true
  - Check risk settings in PROFESSIONAL_RISK_MANAGEMENT.py

Dashboard not accessible:
  - Check firewall: sudo ufw allow 8501
  - Verify dashboard container: docker-compose ps
  - Check logs: docker-compose logs dashboard

Health check failing:
  - Check if bot is running
  - Verify health.txt exists: ls -l bot_data/health.txt
  - Check health monitor: docker-compose logs trading-bot
