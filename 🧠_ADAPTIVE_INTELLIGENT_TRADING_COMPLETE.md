## 🔧 SETUP:

### **1. Install AI Libraries:**
```bash
cd ~/apex_bot
source apex_venv/bin/activate
pip3 install anthropic openai google-generativeai
```

### **2. Add AI API Keys to `.env`:**
```bash
nano .env
```

Add these lines:
```bash
# AI Consultation
ANTHROPIC_API_KEY=sk-ant-your-key-here
OPENAI_API_KEY=sk-your-key-here
GOOGLE_API_KEY=your-gemini-key-here

# AI Budget Control

AI_RATE_LIMIT_PER_MIN=20
AI_DEBATE_ROUNDS=3
```

### **3. Deploy:**
```bash
cd ~/apex_bot
git pull origin continue-from-micro-fix
pkill -f RUN_BOT
nohup python3 RUN_BOT.py > apex.log 2>&1 &
```
