================================================================================
✅ SAFE GIT COMMANDS WE USE:
================================================================================

✅ git stash              - Saves local changes safely
✅ git pull               - Normal pull
✅ git merge --abort      - Cancel incomplete merge
✅ git rebase --abort     - Cancel incomplete rebase
✅ rm .git/*.lock         - Remove lock files

❌ NEVER USE:
❌ git reset --hard       - WIPES VENV AND DEPENDENCIES!
❌ git clean -fd          - Deletes untracked files


================================================================================
💡 IF YOU NEED TO DISCARD LOCAL CHANGES:
================================================================================

DON'T use git reset --hard!

Instead, use:
  git stash              (saves them)
  git stash drop         (if you want to discard)

Or:
  git checkout -- file   (discard specific file)
